## 💡 高级技巧

### 1. 修改推送时间
编辑 `.github/workflows/ai-news-daily.yml`：
```yaml
schedule:
  - cron: '0 0 * * *'   # 北京时间8:00
  - cron: '0 12 * * *'  # 北京时间20:00（每天两次）
```

### 2. 本地测试
运行测试脚本查看效果：
```bash
python test_local.py
```
会生成 `test_email_preview.html` 文件

### 3. 添加自定义RSS源
编辑 `ai_news_collector.py`：
```python
RSS_FEEDS = {
    '你的自定义源': 'https://example.com/rss',
    # ... 其他源
}
```
